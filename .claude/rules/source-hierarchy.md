# Source Hierarchy (자료 우선순위)

> 적용 범위: 사실 검증을 수행하는 모든 에이전트 (Main Agent, researcher, coder, security 등)
> 정본 위치: 본 파일. 다른 에이전트/스킬 정의에서는 1줄 cross-link만 둔다.
> **역할 분리**: 본 파일은 **정적 규범 목록** (어떤 도메인이 Tier 1 도달 강제 대상인지 — 법률·세무 등 일반 도메인 카테고리). 동적 누적 가중치(특정 사례에서 사용자 직관이 옳았던 도메인 + 학습 시 메타 정보)는 `.claude/agent-memory/main/lessons-learned.md`에 따로 둔다. 두 목록은 서로 보완하며 중복이 아니다.

## 개요

사실 확인 시 자료를 다음 4단계 등급으로 분류하고, 상위 등급을 하위 등급보다 우선 채택한다. 학습 데이터에 자주 등장하는 일반론은 Tier 4에 해당하며, 1차 자료(법령·공고문·공식 API 응답)는 Tier 1이다.

## Tier 정의

### Tier 1 (1차 자료)

- 법령 원문, 시행령, 시행규칙, 조례
- 공식 공고문, 정부 부처 고시, 관보
- 공식 API 응답 (실시간 호출 결과)
- 1차 출판물 (학술 논문 원문, 표준 문서 RFC/ISO 등)
- 공식 release notes의 raw 인용

도메인별 예시:
- 법률: 국가법령정보센터, 대한민국 법률 조항
- 청약·주거: 청약Home, 국토교통부 공고문 PDF
- 세무: 국세청 세법, 시행령
- 의료·약품: 식약처 의약품 허가사항, FDA labels
- 금융 규제: 금융감독원 공시, 한국은행 통계
- 소프트웨어: 공식 docs raw, CHANGELOG, source 코드 직접 인용

### Tier 2 (준 1차 자료)

- 공식 FAQ, 공식 가이드라인 (정부/기관)
- 공식 보도자료
- 공식 사용자 매뉴얼
- 공식 GitHub 이슈/PR의 maintainer 답변

### Tier 3 (2차 자료)

- 신뢰할 만한 언론사 기사 (정정·취소 정책 명시 매체)
- 공인 전문가 블로그 (저자 신원·이력 확인 가능)
- 공식 인용을 포함한 위키피디아 항목

### Tier 4 (참고)

- 일반 블로그, 커뮤니티 게시글
- Stack Overflow 답변 (수락된 답변 포함)
- 학습 데이터의 일반론, 통념
- 검증 안 된 추론·비유

## 적용 규칙

1. **상위 등급 미확인 시 단정 금지**: Tier 1을 확인하지 않은 채 Tier 3/4 근거로 단정적 결론을 내려서는 안 된다.
2. **충돌 시 상위 채택**: Tier 1과 Tier 3/4가 충돌하면 Tier 1을 채택한다. Tier 4가 더 자주 등장하더라도 무관.
3. **자료 등급 명시**: 답변에 사용한 출처의 Tier를 명시한다 (`(Tier 1) 공고문 PDF p.3`, `(Tier 4) 일반 통념`).
4. **1차 자료 도달 강제 도메인 (정적 규범)**: 다음 도메인에서는 답변 전 Tier 1 자료를 반드시 확인한다 (deepresearch 의무 호출). 본 목록은 **일반 도메인 카테고리** 차원의 정적 규범이며, 특정 사례 누적에 따른 동적 가중치는 `.claude/agent-memory/main/lessons-learned.md`의 "도메인별 사전 확률 가중치" 절을 참조한다.
   - 법률 (헌법·법률·시행령·시행규칙·조례)
   - 청약·주거 (특히 한국 청약 제도)
   - 세무·회계
   - 의료·약품
   - 금융 규제
   - 최근 1년 내 제도/사양 변경이 잦은 도메인 일반

## Tier 1 도달 불가 시 동작

- 사내 비공개 문서·유료 자료가 1차 자료인 경우 또는 외부 접근 불가 도메인에서는:
  - "Tier 1 미확인" 또는 "1차 자료 도달 불가"를 명시한다
  - 가용한 최고 등급으로 fallback하되, 자신감 라벨을 `추정`으로 표기한다 (epistemic-honesty.md 참조)
  - 사용자에게 1차 자료 제공을 요청한다 ("관련 공고문·법령 조항이 있다면 인용해 주세요")
